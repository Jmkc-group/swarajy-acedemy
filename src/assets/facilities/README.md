# Facility photos

Put real campus photos in a folder named after the facility's `id`
(from `src/data/facilities.js`). They show up automatically in the side panel
that opens when a visitor clicks that card on the Facilities page.

| Folder            | Card                     |
| ----------------- | ------------------------ |
| `campus`          | 14,000 sq. ft. Campus    |
| `library`         | 24-Hour Library          |
| `hostel`          | Residential Hostel       |
| `non-residential` | Non-Residential Facility |
| `mess`            | Food & Mess              |
| `online`          | Online Lectures          |
| `recorded`        | Recorded Lectures        |
| `physical`        | Physical Training        |
| `trekking`        | Monthly Fort Trekking    |

- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (`.webp` keeps the site fast).
- Order and caption come from the file name: `01-library-room.webp` is shown
  first with the caption "Library room".
- Keep each photo under ~300 KB and about 1600px on the long side.
